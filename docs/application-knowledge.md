# ALEKS APPLICATION KNOWLEDGE

**My programs page**
- After successful login, user is navigated to my programs page where it shows tha available classes for teacher under the 'Active programs' section.
- This page also has section that allows the teacher to - 'Create class', 'Import students/roaster' and Redeem 'ConnectED products'.
- The class cards each have its 'Class Action' dropdown that allows the teacher to - 'Manage class roaster', 'Add content', 'Archieve class', 'Edit class info' and 'Copy class code'.

**Student roaster page**
- When a teacher user click on 'Manage class roaster' from the 'Class actions' dropdown for any class on the 'My programs page' then the user is navigated to the student roaster page of that class.
- On this page the teacher has options to edit the teacher and student roaster using tabs - 'Student','Teacher' present under the 'Roaster' heading.
- This page also displays list of student/teacher added to respective roaster.
- It has a 'Edit student roaster' button using which teacher can edit the student roastrer.

**Edit roaster page**
- If a teacher click on 'Edit student/teacher roaster' button on 'Roaster page' then the user is navigated to 'Edit roaster page'
- This page allows teacher to add existing students to roaster or create new students.
- This page also displays a list of available students under the 'School Student roaster' section along with a search bar to search for required students.
- From the 'School Student roaster' section, teacher can search required students, select them and then add them to 'Class student roaster using 'Add students button'
- After adding the students would be displayed under the 'Class Student roaster' section.
- User must click on 'Save button' under the 'Add students' button to save the changes after confirmation.

**User menu**
- A button for user menu is present on top right corner of each page.
- Clicking on that button opens the user menu popup that has Accont level actions for - 'Manage account', 'Help' and 'Logout'
- After user has completed his work it can logout using this menu.
